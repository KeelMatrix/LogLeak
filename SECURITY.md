# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately before any public disclosure:

1. Email **keelmatrix@gmail.com** with the affected LogLeak version, security impact, and sanitized reproduction steps.
2. If private vulnerability reporting is enabled in GitHub for this repository, you may also open a private GitHub Security Advisory.

Do not include production credentials or other live sensitive data.

Please do not disclose a suspected vulnerability publicly until KeelMatrix has had an opportunity to investigate and coordinate a response.

## Supported versions

The latest stable package version receives security fixes. Pre-release and development builds are not supported versions.
