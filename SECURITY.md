# Security Policy

## Reporting a vulnerability

This repository is currently private, and GitHub's **Security** tab → **Report a vulnerability** flow is therefore not available yet. When the repository becomes public, that GitHub private-reporting flow is the primary route; it must be enabled in the repository's Security settings before reporters use it. The route becomes publicly available when the repository does. Do not file a suspected vulnerability in a public issue.

The previously listed `security@keelmatrix.dev` address has been removed because its domain currently publishes no MX record and the host does not resolve to a usable mail service. Do not use that address.

Until a verified private route is enabled, do not disclose a suspected vulnerability publicly; the repository owner must first make the GitHub Security-tab route available or provide a separately verified private address. Include a concise description, affected version, reproduction steps that use synthetic values, and any safe evidence needed to reproduce the issue. Do not include production credentials or other live sensitive data.

Please do not disclose a suspected vulnerability publicly until KeelMatrix has had an opportunity to investigate and coordinate a response.

## Supported versions

The latest stable package version receives security fixes. Pre-release and development builds are not supported versions.
