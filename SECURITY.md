# Security policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to `security@keelmatrix.dev`. Include a concise description, affected version, reproduction steps that use synthetic values, and any safe evidence needed to reproduce the issue. Do not include production credentials or other live sensitive data.

Please do not disclose a suspected vulnerability publicly until KeelMatrix has had an opportunity to investigate and coordinate a response.

## Supported versions

The latest stable package version receives security fixes. Pre-release and development builds are not supported versions.
